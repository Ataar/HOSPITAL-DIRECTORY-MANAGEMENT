# Doctor Directory - Angular

Angular standalone project for searching the doctor directory by:
- Doctor name
- Department
- Floor
- Room number
- Timing

## Run

```bash
npm install
npm start
```

Then open the URL shown by Angular CLI, normally `http://localhost:4200`.

## Main files

- `src/app/app.component.html` - UI
- `src/app/app.component.scss` - styling
- `src/app/app.component.ts` - search/filter logic
- `src/app/data/doctors.ts` - directory data
- `src/app/models/doctor.model.ts` - TypeScript model
